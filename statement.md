# Project Statement

## Problem Statement

Basic image inspection often requires checking several visual properties separately, such as edges, sharpness, lighting and visible shapes. For a student or beginner working with computer vision, these steps can be difficult to organize into one repeatable workflow.

VisionCheck addresses this problem by providing a simple command-line tool that accepts an image, performs basic preprocessing, calculates image-quality measurements, detects visible geometric shapes and produces saved results.

## Scope

The project focuses on classical computer vision techniques using OpenCV. It does not attempt to replace advanced object-detection systems. Its purpose is to demonstrate a complete, understandable image-processing workflow from input to analysis and output.

## Target Users

- Computer vision students
- Beginners learning OpenCV
- Students testing image-processing techniques
- Users who need quick command-line image inspection

## High-Level Features

1. Image preprocessing and edge detection.
2. Image-quality measurement.
3. Contour and shape detection.
4. Annotated output generation.
5. JSON/text result reporting.
6. Command-line execution and automated tests.
